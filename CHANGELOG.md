# Changelog

## v1.0.0 — Initial public source release
- Decoder-only Transformer in PyTorch.
- Trainable byte-level BPE tokenizer.
- CPU training and autoregressive inference.
- Local ChatGPT-style browser interface with streaming and generation controls.
- Windows installation, training, start, and evaluation scripts.
- Model card and architecture documentation.

The included Nano configuration is a small research experiment, not an instruction-tuned assistant.
